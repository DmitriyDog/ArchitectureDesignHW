#### Диаграмма компонентов сервиса магазина
Компонент "Контроллер магазина" принимает и обрабатывает http запросы от API Gateway, а также отправляет обратный ответ.
Компонент "Каталог товаров" обрабатывает полученный список товаров из магазина.  
Компонент "Репозиторий товаров" обрабатывает запросы функций каталога товаров и обращается к БД.  
Компонент "Обработчик покупок" отправляет платежные запросы в клиент платежной системы, получает результат и в зависимости от него через клиент инвентаря отправляет запросы на добавление предмета в инвентарь.  
Компонент "Клиент платежной системы" напрямую работает с платежной системой. Он передает платежные данные, оформляет платеж и получает результат денежной транзакции.
Компонент "Клиент инвентаря" напрямую передает в БД запросы на изменение инвентаря. В случае данного вариант использования - запрос на добавление предмета в инвентарь.

### Часть 3
#### Модель БД для выбранного варианта использования
У каждого игрока есть уникальный идентификатор, к которому закреплен свой инвентарь и платежные данные (может быть несколько у одного игрока). Таблица инвентаря подразумевает собой набор предметов,
которые закреплены за разными игроками с помощью внешнего ключа. Она также содержит информацию о состоянии конкретного предмета в инвентаре конкретного игрока.  
Предметы в инвентаре игрока представляют собой экземпляры предметов, которые хранятся в таблцие "Предметы". В ней описываются характеристики предметов. Таблица "ТоварМагазина" содержит информацию о предмете,
которая используется в магазине, включая оставшееся количество (для ограниченных по количеству предметов), размер скидки и т.п.
