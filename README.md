# ArchitectureDesignHW
Развлекательная компания хочет, чтобы **MMORPG-игра** от первого лица была доступна через браузер  
**Пользователи:** миллионы+ (они надеются)  
## Требования:  
Пользователи выбирают карту, на которой хотят играть, а затем сражаются со случайно выбранными игроками примерно одинакового мастерства.  
Игроки могут «нарядить» своих персонажей навыками/снаряжением, отправив компании деньги.  
Можно использовать в любом «современном» веб-браузере.  
Полное погружение (звук, графика и т. д.).  
Игроки могут «общаться» с другими игроками, но только с теми, кто находится «в пределах досягаемости».  
Игроки могут создавать турниры только по приглашению.  
Гости могут наблюдать за всеми игроками, не будучи замеченными/взаимодействовать (призраки).  
Игроки могут создавать новые карты, оружие и правила.  
### Дополнительный контекст:
Игровая производительность имеет высокий приоритет, но масштабируемость тем более  
Если эта игра будет успешной, компания планирует извлечь хорошие части в качестве основы, которую они смогут продать.  
Самые большие расходы — это высококвалифицированные художники, создающие визуальный вид
