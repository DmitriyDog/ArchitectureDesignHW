# Лабораторная работа №5
## Тема: Реализация архитектуры на основе сервисов (микросервисной архитектуры)

### Цель работы
Получить опыт организации взаимодействия сервисов с использованием контейнеров Docker и настроить непрерывную интеграцию с автоматическим тестированием.

---

## Реализованная архитектура

В рамках работы реализовано приложение, состоящее из трех взаимодействующих контейнеров:

1. **frontend** — клиентская часть на Python Flask, отображающая интерфейс и получающая данные от backend;
2. **backend** — серверная часть на Python Flask, реализующая API и бизнес-логику работы со счетчиком посещений;
3. **db** — база данных PostgreSQL, используемая для хранения данных приложения.

Контейнеры запускаются с помощью `docker compose` и взаимодействуют друг с другом по внутренней сети Docker.

## Состав контейнеров

### 1. Frontend
Контейнер `frontend` запускает Flask-приложение на порту 5000. Приложение выполняет HTTP-запросы к backend и отображает полученные данные пользователю.

**Основные функции:**
- Отображение приветственного сообщения
- Проверка связи с backend
- Отображение значения счетчика посещений

**Код приложения (app.py):**
```python
import requests
from flask import Flask

app = Flask(__name__)

@app.route('/')
def hello():
    try:
        response = requests.get('http://backend:5000/', timeout=5)
        backend_message = response.text
        return f'Frontend получил ответ от: <br> {backend_message}'
    except requests.exceptions.RequestException as e:
        return f'Frontend не смог достучаться до backend. Ошибка: {e}'

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5001, debug=True)
```

### 2. Backend
Контейнер backend реализован на Flask и предоставляет REST API для работы со счетчиком посещений, который хранится в PostgreSQL.

#### Эндпоинты:

GET / — возвращает текущее значение счетчика из PostgreSQL и увеличивает его на 1

**Код приложения (app.py):** 
```python
import os
import psycopg2
from flask import Flask
import time

app = Flask(__name__)

def get_db_connection():
    max_retries = 5
    retry_delay = 2
    
    for attempt in range(max_retries):
        try:
            conn = psycopg2.connect(
                host=os.getenv('POSTGRES_HOST', 'db'),
                database=os.getenv('POSTGRES_DB', 'labdb'),
                user=os.getenv('POSTGRES_USER', 'user'),
                password=os.getenv('POSTGRES_PASSWORD', 'password'),
                port=5432
            )
            return conn
        except psycopg2.OperationalError:
            if attempt < max_retries - 1:
                time.sleep(retry_delay)
                continue
            else:
                raise

@app.route('/')
def hello():
    try:
        conn = get_db_connection()
        cur = conn.cursor()
        
        cur.execute("""
            UPDATE hits 
            SET counter = counter + 1, last_updated = CURRENT_TIMESTAMP 
            WHERE id = 1 
            RETURNING counter
        """)
        
        if cur.rowcount == 0:
            cur.execute("INSERT INTO hits (id, counter) VALUES (1, 1) RETURNING counter")
        
        count = cur.fetchone()[0]
        conn.commit()
        
        cur.close()
        conn.close()
        
        return f'Backend с PostgreSQL: Этот запрос виден {count} раз.\n'
        
    except Exception as e:
        return f'Backend: Ошибка подключения к PostgreSQL: {str(e)}\n'

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000, debug=True)
```

### 3. Database
Контейнер db использует PostgreSQL 15 и хранит данные приложения. При первом запуске автоматически создается таблица hits через скрипт инициализации.  

**Скрипт инициализации:**
```sql
CREATE TABLE IF NOT EXISTS hits (
    id SERIAL PRIMARY KEY,
    counter INTEGER DEFAULT 0,
    last_updated TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

INSERT INTO hits (id, counter) 
SELECT 1, 0 
WHERE NOT EXISTS (SELECT 1 FROM hits WHERE id = 1);
```
